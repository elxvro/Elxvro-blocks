# ELXVRO Blocks v0.13.0 — Material Response

This release keeps the original ELXVRO Blocks app structure and upgrades the physical feel of gameplay.

## Incremental steps
- v0.12.1 — Physical surface response: directional highlights, contact occlusion and material micro-detail on block faces.
- v0.12.2 — Material-weighted board impact: glass/crystal react sharply, stone/marble feel heavier, leaf remains soft.
- v0.12.3 — Layered real-material audio: fracture transient + body/impact layer for multi-line clears and high combos.
- v0.12.4 — Material-specific haptics: different tactile signatures for glass, crystal, wood, stone, marble and leaf.
- v0.12.5 — Physical placement settle: short drop, overshoot and theme-specific tilt when blocks land.
- v0.13.0 — Finalized material response pass with the v0.12.0 fracture engine preserved.

Menus, modes, profile, missions, store, settings and game-state logic remain intact.
