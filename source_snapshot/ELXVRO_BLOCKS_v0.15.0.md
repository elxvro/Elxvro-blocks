# ELXVRO Blocks v0.15.0 — Bright Fracture + Playlist

This release responds directly to gameplay feedback from v0.14.0.

## Music
- Replaces the single endlessly-looped BGM behavior with a 3-track playlist.
- The same track is never selected twice in a row.
- New CC0 tracks are normalized during the GitHub build for consistent volume.
- Existing sound effects and material audio remain intact.

## Visual brightness
- All six gameplay themes use brighter background, board, cell and block palettes.
- Ambient theme glow is stronger while preserving each material identity.
- Dark areas remain for contrast, but the board and blocks read more clearly.

## Fracture spread
- More debris per cleared cell in high-quality mode.
- Glass/crystal fragments travel farther and faster.
- Wood/stone/marble/leaf debris has broader material-specific motion.
- Shockwaves now include a wider secondary ring.
- Multi-line clears create localized aftershock rings across the cleared area.
- Impact rays extend farther across the board.

Core scoring, modes, menus, save-state logic and progression are unchanged.
